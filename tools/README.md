# Outil de creation administrateur

Depuis PowerShell, dans le dossier du projet :

```powershell
C:\xampp\php\php.exe tools\create_admin.php Admin Forge admin@forgemarket.tg "+228 90000000" "ChoisirUnMotDePasseFort"
```

Le script fonctionne uniquement en ligne de commande et hash le mot de passe avant de l'enregistrer.
